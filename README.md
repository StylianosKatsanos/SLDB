# SLDB Setup Guide

## 1. Prerequisites

For the proper operation of the project, the following tools are needed:

1. Download Python (>=3.12 recommended - check): [Download Here](Https://www.python.org)
2. Download Git: [Download here](https://git-scm.com/downloads)
3. Update pip: `python -m pip install --upgrade pip`

Do not forget to clone Repository: `git clone https://github.com/StylianosKatsanos/SLDB`

## 2. Setup

1. Create virtual environment: `python -m venv .venv`
2. Activate the virtual environment: `.\.venv\Scripts\Activate.ps1`
3. Install dependencies: `pip install -e .`

## 3. Tests:

1. Run `python -m pytest your_test`
2. To run all tests, run: `pytest`
